# Product Overview

## Purpose

หน้าแรก (homepage) เว็บพอร์ทัลบริษัทประกันภัยชั้นนำ — เว็บองค์กรขนาดใหญ่ เนื้อหาแน่นเป็นระบบ
(อ้างอิง IA แบบเว็บโรงพยาบาลใหญ่ เช่น Bangkok Hospital แต่แปลงเป็นธุรกิจประกัน) ดูน่าเชื่อถือ
มั่นคง เป็นมืออาชีพ "ดูแพง" รันได้ทันทีในเบราว์เซอร์. เป้าหมายหลัก: ทดสอบคุณภาพ **ดีไซน์ +
ตรรกะคำนวณเบี้ยประกัน** ในงานชิ้นเดียวที่สมบูรณ์พร้อมนำเสนอ.

## Target Users

- ผู้ที่กำลังหาซื้อ/เปรียบเทียบประกัน — ต้องการเห็นประเภทประกัน, โปรโมชั่น, คำนวณเบี้ยเองได้ทันที
- ลูกค้าเดิม — ทางลัด เช็กกรมธรรม์ / แจ้งเคลม / ต่ออายุ / ดาวน์โหลดเอกสาร
- ผู้ประเมินงาน (rubric) — ตรวจความครบ section, ดีไซน์, ความสมบูรณ์ด้านภาพ, ความถูกต้องเครื่องคำนวณ

## Key Features

- พอร์ทัล homepage เนื้อหาแน่น 12+ section: utility bar, sticky header, hero ซ้าย-ขวา,
  ประเภทประกัน (≥6–8 การ์ด), บริการ (≥12 ไอคอน), โปรโมชั่น (≥8 การ์ด), เครื่องคำนวณเบี้ย,
  แถบสถิติ, บทความ (≥8 การ์ด), testimonials, ดาวน์โหลดแอป (phone mockup), footer ไดเรกทอรี
- เครื่องคำนวณเบี้ยประกัน: เลือกประเภท + อายุ + ทุนประกัน → เบี้ยโดยประมาณทันที พร้อม validation
- Interaction จริง: เมนู dropdown/hamburger, ตัวกรองประเภทประกัน, สไลด์ testimonial, hover states

## Business Objectives

- คะแนน rubric (เต็ม 100): section completeness 18, design quality 20, visual completeness 18,
  เครื่องคำนวณถูกต้อง+validate 18, responsive 12, interaction 8, a11y 4, code/TS 2
- เกณฑ์ผ่าน: ทุก acceptance checklist (1–11) ผ่านเมื่อตรวจด้วยตา/DevTools ที่ 375 / 768 / 1440px

## Non-Goals

- ไม่มี backend จริง / ฐานข้อมูล / auth จริง — ข้อมูลทั้งหมดเป็น mock ในโค้ด
- ไม่มีระบบชำระเงิน, การเชื่อม API ภายนอกจริง (นอกจากดึงรูป placeholder)
- ไม่ทำหน้าอื่นนอกจาก homepage — ลิงก์ปลายทางเป็น placeholder
- ไม่รองรับหลายภาษาจริง (toggle TH/EN เป็น UI เฉยๆ ไม่ต้องแปลทั้งหน้า)
