## Lessons Learned

(promote ไป stack-nextjs.md — path-scoped)

- **Discovery**: vitest ไม่รู้จัก path alias `@/` ของ tsconfig เอง — ต้องตั้ง `resolve.alias` ใน `vitest.config.ts` (`{"@": fileURLToPath(new URL(".", import.meta.url))}`) ไม่งั้น test fail "Failed to load url @/..." (collect 0 tests). — **Why**: pure-logic-first เขียน test ก่อน, alias พังตั้งแต่รอบแรก เสียรอบ debug.
- **Discovery**: Next 16 default = Tailwind v4 (CSS-first `@import`/`@theme`) แต่ spec lock `@tailwind` directives + `theme.extend` ใน `tailwind.config.ts` = v3 -> ต้อง pin `tailwindcss@^3.4` + autoprefixer + `postcss.config.mjs` เอง. ปล่อยให้ดึง latest = v4 -> directive/config ไม่ทำงาน. — **Why**: design.md เป็น source of truth; เลือก major version ตาม artifact ที่ lock ไม่ใช่ default ของ framework.
- **Discovery**: chrome-devtools `resize_page` ผูกกับหน้าต่าง OS จริง — macOS Chrome มี min width ~485px, ตั้ง 375 ไม่ลง (ได้ 485). ใช้ `emulate` viewport `375x812x2,mobile,touch` (CDP device metrics) เพื่อทดสอบ 375 จริง. — **Why**: REQ บังคับ verify 375; resize อย่างเดียวจะรายงาน mobile ผ่านบน 485 ที่ไม่ใช่ขนาดจริง.
