## Lessons Learned

- **Pattern**: blur-triggered calculate ต้อง guard ว่า "ทุก field ครบ" (`type && age.trim() && sum.trim()`) ก่อน call — ไม่อย่างนั้น blur ฟิลด์กลางคัน (เช่น ยังไม่ได้กรอก sum insured) trigger validation → โชว์ error ทั้งที่ยังกรอกไม่จบ (false-positive UX). วาง blur ที่ฟิลด์สุดท้าย (sum insured) ไม่ใช่กลางคัน. **Why**: user กรอกยังไม่จบแต่ error ปรากฏ flash = UX พัง; session นี้เจอ bug นี้ใน artifact เดิม.

- **Discovery**: ไฟล์ component ที่ task สั่งสร้างอาจมีอยู่ก่อนแล้วเป็น partial artifact จาก session ก่อน (formatter hook อาจเขียนโครงให้ หรือ task ก่อนหน้าทิ้งไว้) — ก่อน `Write` overwrite, `Read`/`ls` ก่อน. ถ้ามี → Edit ตรงจุดที่ต้องแก้ แทนเสียเวลาเขียนใหม่หมด + รู้ว่าอะไร changed. **Why**: task 6 เจอ PremiumCalculator.tsx 7.2KB อยู่แล้วพร้อม bugs 3 จุด; ถ้า Write ทับโดยไม่อ่านจะเสียเวลา + ไม่เห็นว่า partial version ต่างจาก design อย่างไร.

- **Pattern**: `validateXxx()` คืน `null` เมื่อ valid แต่ type ของ argument ยังเป็น `T | null` (ไม่ auto-narrow ผ่าน function call) — tsc จะ error TS2345 "Type 'null' is not assignable to parameter of type 'T'". ใช้ `as T` assertion หลัง guard (safe เพราะ lib contract รับประกัน non-null เมื่อ error=null) หรือเปลี่ยน lib ให้ return type predicate. **Why**: tsc catch bug จริง (ลืมว่า type ยังอาจเป็น null ได้) แต่ lib contract ไม่ได้ encode ใน type; ต้อง assert หรือ refactor.
