## บทเรียนที่ได้ (Lessons Learned)

- **Pattern**: inline SVG opacity ที่มี objective anchor (≥X) ต้องคุม effective ทั้ง chain — `<g opacity>` ครอบ `path opacity` = คูณกัน; ตั้ง ancestor = 1 หรืออ่าน computed ไม่ใช่แค่ attr ของ path - กัน false-pass (attr ผ่าน, ตาเห็นจาง)
- **Pattern**: tap target ≥40px บน element ที่ visual เล็ก (dot/bar) ทำด้วย button เป็น hit area (h-10 w-10) + visual เป็น `<span>` ลูก + `group-hover` - คงดีไซน์เล็กแต่ผ่าน a11y tap
- **Discovery**: playwright plugin ไม่มี `emulateMedia` → reduced-motion/print emulation ต้องใช้ chrome-devtools MCP (`emulate`) - เลือก tool ตาม capability ก่อนเริ่ม verify
