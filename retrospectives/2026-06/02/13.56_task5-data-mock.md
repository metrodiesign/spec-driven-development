## Lessons Learned

- **Pattern**: `Article.category` เป็น free-form `string` (หัวข้อบทความ) จงใจคนละแกนกับ
  `InsuranceCategory` taxonomy (filter สินค้า) — อย่าบังคับ article เข้า enum เดียวกับ product;
  ใส่คอมเมนต์กำกับว่า "label string, distinct from taxonomy" กัน task หลัง (Articles UI) เผลอ wire
  เข้า filter chip. — **Why**: type design.md แยกไว้แล้ว (`category: string` vs `InsuranceCategory`);
  รวม enum = สูญความหมาย + filter บทความที่ spec ไม่ได้สั่ง (scope creep).
- **Discovery**: data-only task verify เร็วด้วย `tsc --noEmit` อย่างเดียวพอเป็น gate จริง — ไม่ต้อง
  build/browser. completeness ("ทุกหมวดมีสมาชิก") ปิดด้วย filters.test (fixture) + non-optional
  `category` field ที่ tsc บังคับ; count การ์ด (≥8/≥12) เป็น verify รอง อ่านจากไฟล์ได้. — **Why**:
  ประหยับรอบ — data ไม่มี runtime logic, integrity = compile-time ทั้งหมด.
