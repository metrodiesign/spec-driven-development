### Architecture Decisions

- **`lg:` split แทน `md:` สำหรับ desktop-nav vs hamburger**: Tailwind `md:` = min-width 768
  inclusive -> nav จะโผล่ที่ 768 พอดีชน hamburger = overflow. ใช้ desktop nav `hidden lg:flex`,
  hamburger `lg:hidden` -> ≤768 (และ tablet ถึง 1023) เห็น hamburger สะอาด.
- **`suppressOpenRef` กัน ESC reopen**: ESC ปิด + `trigger.focus()` -> `onFocus` ของ trigger
  เปิด dropdown ซ้ำทันที. ใช้ ref flag เซ็ตก่อน focus, `onFocus` เช็คแล้ว return + reset ->
  ปิดจริง, แต่ tab กลับเข้ามาทีหลังยังเปิดได้ (คง REQ-3.2 focus-open).
- **UtilityBar ไม่ sticky, Header sticky**: utility bar เลื่อนหายได้, header ติดบน — pattern
  พอร์ทัลมาตรฐาน.
