## Lessons Learned

- **Pattern**: vuln audit แยก dev-only vs prod-core ก่อนตัดสิน — vitest UI server "critical" + esbuild moderate อยู่ใน **devDependency chain** (vitest→vite→esbuild), prod build ไม่ bundle -> bump vitest major (v2→v4, API `defineConfig`/`test.include`/`resolve.alias` เสถียร) แก้ได้สะอาด ไม่แตะ prod. แต่ postcss moderate เป็น **next bundle เอง** (`next→postcss@8.4.31`) -> `fix --force` downgrade next 9.x = ห้าม, defer. — **Why**: เหมารวมทุก vuln เป็น "ต้อง fix --force" จะ downgrade core พังกว่าตัว vuln; แยก dependency tree (`npm ls postcss`) ชี้ว่าตัวไหน fix ได้จริง.
- **Pattern**: pin next/react version ด้วย `npm view next@16 version` ก่อนเขียน package.json — เดาเลข patch (16.0.1) อาจไม่มีจริง -> install fail. — **Why**: เสียรอบ install; query registry ก่อน pin ถูกครั้งเดียว.
