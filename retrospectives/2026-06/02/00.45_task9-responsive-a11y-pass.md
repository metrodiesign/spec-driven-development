## สิ่งที่ควรปรับปรุง (What Could Improve)

- a11y probe ผมเขียน exclusion list ของ input type ไม่ครบ (ลืม `type=search`) -> สร้าง false positive ที่เกือบทำให้ไล่แก้ผิด. ควร base accessible-name ของ input บน `i.labels.length || aria-label` ตั้งแต่แรก แทน heuristic textContent.
- ไม่ได้ตรวจ favicon (เจอ 404 ใน console) ตั้งแต่ viewport แรก — รายงานช้าไปนิด แม้ไม่ใช่ REQ.

## อุปสรรคและการแก้ (Blockers & Resolutions)

- **อุปสรรค**: clientWidth ไม่ตรงกับ viewport ที่ตั้ง (360 vs 375) เพราะ scrollbar -> ทดสอบ boundary 768 ไม่ตรง.
  **การแก้**: ตั้ง window width = 783 (768 + scrollbar 15) ให้ clientWidth=768 เป๊ะ แล้ว media query `lg:` evaluate ถูกต้อง.
- **อุปสรรค**: a11y probe รายงาน input ไม่มีชื่อ ขัดกับ inputNoLabel=0.
  **การแก้**: ตามไปดู type จริง = `search` (นอก exclusion list) + มี `<label for>` -> สรุปว่า false positive ของ probe ไม่ใช่บั๊ก.
