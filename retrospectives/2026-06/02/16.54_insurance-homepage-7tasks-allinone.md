## Lessons Learned

- **Pattern**: global `:focus-visible` focus-ring ใช้ **`outline`** ไม่ใช่ box-shadow ring — box-shadow ring (`@apply ring-2 ring-primary ring-offset-2`) composite ผ่าน `--tw-ring-shadow` เข้า `box-shadow` property; element ที่มี box-shadow ของตัวเอง (`shadow-card`, หรือ utility `shadow-*`) เขียน `box-shadow` ทับใน utilities layer (ชนะ base layer) → ring layer = 0 → **ring มองไม่เห็นบนการ์ด/ปุ่ม** (chip/element ที่ไม่มี shadow ยังเห็น = บดบังบั๊ก). แก้: `:focus-visible { @apply outline outline-2 outline-offset-2 outline-primary }` + `[data-surface="dark"] :focus-visible { @apply outline-accent }` — outline ไม่ยุ่งกับ box-shadow cascade เลย, single-source per-surface เหมือนเดิม. และ **ห้าม `focus:outline-none` บน input** ที่พึ่ง outline-based ring (Tailwind `outline-none` = `outline:2px solid transparent` ทับ :focus-visible → โฟกัสมองไม่เห็น). — **Why**: lesson เดิมแนะ box-shadow ring (`--tw-ring-color`) แต่ใช้งานจริงพังกับ `shadow-card`/Button ทั้งหน้า; verify ด้วย `--tw-ring-color` ตั้งถูกอย่างเดียว false-pass (var ตั้งแต่ box-shadow ไม่ render). outline กันทั้ง class ของ regression.
- **Discovery**: verify focus-ring ต้องใช้ **keyboard Tab จริง** (`browser_press_key Tab` → อ่าน `document.activeElement` outline) ไม่ใช่ programmatic `el.focus()` — ใน headless Chromium `.focus()` ทำ `:focus-visible` heuristic เพี้ยน: `el.matches(':focus-visible')` คืน true แต่ `getComputedStyle(el).outline` คืน UA default ปลอม `1.5px solid currentColor` สลับไปมาระหว่าง element (element เดียวกัน focus ตรงคืน 2px primary, อ่านตอนไม่ใช่ active คืน 1.5px). — **Why**: เกือบไล่แก้ "การ์ด InsuranceTypes ring ไม่ขึ้น" ทั้งที่ CSS ถูก — เป็น measurement artifact ของ programmatic focus; Tab จริง trigger :focus-visible เสถียร พิสูจน์ 2px primary/accent ครบทุกชนิด.
- **Discovery**: ลบ App Router route แล้ว `tsc --noEmit` แดง `TS2307 Cannot find module '../../app/<route>/page.js'` จาก stale `.next/types/validator.ts` (tsconfig include `.next/types/**`). `next build` regenerate validator ลบ reference ที่หาย — **อย่า `tsc` ก่อน rebuild หลังลบ route**, รัน build ก่อน. — **Why**: เสียรอบสรุปว่า code พังทั้งที่เป็น artifact เก่า; throwaway verify route (task 5) ลบแล้วเจอเคสนี้.
