## Lessons Learned

- **Pattern**: design.md ที่ประกาศ signature แบบไม่มี body (`export const BASE_RATE: Record<...>`,
  `export function ageFactor(age): number;`) ให้ implement ด้วย **ชื่อเป๊ะตาม design** — task 9 (UI) จะ
  `import { BASE_RATE }` ตรงๆ. เผลอตั้ง `BASE_RATES` (เติม s) ตอนแรก -> ต้องแก้ย้อน + ทิ้ง placeholder junk.
  — **Why**: ชื่อ public API ที่ task ปลายน้ำพึ่งต้อง match contract ใน design ไม่งั้น import พังหรือเสียรอบ
  rename; design เป็น contract ไม่ใช่ข้อเสนอแนะ.
