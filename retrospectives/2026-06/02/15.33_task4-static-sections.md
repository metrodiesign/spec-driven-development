## Lessons Learned

- **Pattern**: decorative SVG ที่ wrapper ตั้งสีเดียว (`text-accent`) แต่ต้องการสี token ที่ 2 บางชิ้น (เช่นเครื่องหมายถูก primary บนวงกลม accent) -> ใส่ `className="text-primary"` ที่ element นั้นตรงๆ + `stroke/fill="currentColor"` (currentColor resolve ต่อ element ตาม computed color ของมันเอง). อย่าเผลอ hardcode `#FFFFFF`/`#13266B` ใน fill/stroke ของ decorative SVG (ละเมิด REQ-2.3/17.5 — ต่างจาก brand-logo carve-out 2.4). ส่วนสีเดียวกับ wrapper ใช้ `currentColor` + `opacity` แทนสีขาวดิบ. — **Why**: เกือบใส่ raw hex รอบแรกในแบนเนอร์ hero; per-element token class ให้ multi-color SVG โดยคง no-raw-hex โดยไม่ต้องแตก SVG เป็น gradient/รูปจริง.
