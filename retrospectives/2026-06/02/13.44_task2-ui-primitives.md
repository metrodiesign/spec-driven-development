## Lessons Learned

- **Pattern**: Icon registry type-safe ใช้ `const ICONS = {...} satisfies Record<string, ReactNode>` แล้ว `type IconName = keyof typeof ICONS` — ได้ literal key union (autocomplete + typo fail tsc) พร้อม constraint ค่าเป็น ReactNode ในประกาศเดียว. อย่าใช้ `: Record<string, ReactNode>` ตรงๆ เพราะจะ widen key เป็น `string` -> IconName หลวม (typo ไม่ถูกจับ). — **Why**: data task ฝั่งหลัง (Service.icon: IconName) พึ่ง union แคบนี้กัน icon หาย/กล่องว่าง; `satisfies` คงทั้ง narrow key และ value-check.
- **Pattern**: fallback art / decorative SVG ที่ห้าม raw hex (REQ-15.3) ทำ gradient ด้วย Tailwind utility (`bg-gradient-to-br from-primary to-primary-dark`) + motif เป็น `currentColor` (`text-accent`) — ไม่ใช่ `<linearGradient><stop stop-color="#...">` ที่บังคับ hex ดิบ. varied per category = map category -> IconName ต่างกัน reuse Icon. — **Why**: SVG gradient stop รับแต่ค่าสีตรง (ไม่กิน Tailwind class) -> ถ้าทำ gradient ใน SVG จะละเมิด no-hardcode-hex; ย้าย gradient ขึ้น wrapper div แก้ครบทั้ง varied + token-only.
