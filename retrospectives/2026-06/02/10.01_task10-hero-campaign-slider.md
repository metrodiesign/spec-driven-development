### Architecture Decisions

- **h1 invariant**: banner เดิมถือ `<h1>` เดียวของหน้า. 4 สไลด์ที่ title เป็น h1 = h1=4 (ผิด); title เป็น h2 ทั้งหมด = h1=0. แก้โดย slide title = `h2` + promote หัวข้อแผงซ้าย "เริ่มต้นกับวิริยะ" (คงที่, persistent) จาก `h2`→`h1` เปลี่ยนแค่ tag → h1=1 เสถียร ไม่ขึ้นกับ slider state. (เลือก persistent heading แทน dynamic active-slide-as-h1 เพื่อความเรียบง่ายและ probe เสถียร)
- **reuse `lib/slider.ts`**: `nextSlide/prevSlide/goToSlide` มี+test wrap-around แล้ว → UI แค่ orchestrate, ไม่ duplicate index math
- **autoplay gate ใน JS**: globals.css คุมแค่ transition/animation; `setInterval` เป็น JS ต้อง gate `prefers-reduced-motion` เองด้วย `matchMedia` (REQ-4.8)

## บทเรียนที่ได้ (Lessons Learned)

- **Pattern**: carousel ที่ใส่แทน element ที่เคยถือ `<h1>` ต้องคง h1=1 — slide titles ทั้งหมดอยู่ใน DOM พร้อมกัน (translateX ไม่ unmount) → title เป็น h1 = h1=N. แก้: title = h2 + promote heading คงที่ตัวอื่นเป็น h1 (เปลี่ยนแค่ tag). - สำคัญเพราะ regress h1 เงียบเมื่อ refactor banner→slider
- **Discovery**: React สังเคราะห์ `onMouseEnter/onFocus` จาก native delegation ที่ root → `el.dispatchEvent(new MouseEvent('mouseenter'))` ไม่ trigger handler → pause autoplay ไม่เกิด. ทดสอบ pause/autoplay ให้ใช้ Playwright `page.hover()` จริง หรือ `emulateMedia({reducedMotion:'reduce'})` ปิด autoplay เพื่อ test deterministic (+ ได้ verify reduced-motion พร้อมกัน). - นำไปใช้กับทุก carousel/autoplay test
- **Discovery**: headless Chromium scrollbar = 0px (overlay) → สูตรชดเชย +15px (จาก lessons ที่เขียนสำหรับ scrollbar จริง) over-compensate. ยืนยัน `clientWidth === target` เป๊ะก่อนเชื่อผล boundary เสมอ. - นำไปใช้ทุก overflow test ที่ viewport boundary
