## อุปสรรคและการแก้ (Blockers & Resolutions)

- **อุปสรรค**: grep hex `c2293d` ใน built CSS ไม่เจอ → กังวล token ไม่ compile.
  **การแก้**: รู้ว่า Tailwind v3 emit เป็น `rgb(194 41 61/...)` → grep รูป rgb เจอ, ยืนยัน compile ถูก.

  **การแก้**: ใช้ `input[id$="-age"]` / `input[id$="-sum"]` จาก `useId` แทน.

## บทเรียนที่ได้ (Lessons Learned)

- **Pattern**: form ที่มี pure validation lib อยู่แล้ว → UI เก็บ raw string, parse `""`→null ที่เหลือโยน
