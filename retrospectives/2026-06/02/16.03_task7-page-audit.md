## Lessons Learned

- **Pattern**: contrast-audit probe ที่ไต่ ancestor หา bg ต้องอ่าน **ทั้ง `backgroundColor` และ `backgroundImage`
  (gradient/รูป)** — โปรเจกต์นี้พื้นเข้มหลายที่ทำด้วย `bg-gradient` (navy) ซึ่ง `backgroundColor` = `rgba(0,0,0,0)`
  -> probe ที่อ่าน backgroundColor อย่างเดียวจะ "ทะลุ" ไปเจอ light Container ใต้ -> รายงาน white-on-navy h2
  เป็น ratio 1.07 (ปลอม ทั้งที่จริงสูง ~13). ก่อนสรุป contrast fail ให้ dump ancestor chain ดู `backgroundImage`
  ด้วย; ถ้าเจอ gradient/image = bg จริงเป็นสีนั้น ไม่ใช่ fall-through. — **Why**: เกือบรายงาน a11y defect ปลอม
  - ไปแก้สี text ที่ถูกอยู่แล้ว; ตรงคลาส false-positive เดียวกับ SVG-geometry overflow (probe อ่าน property
    ไม่ครบ -> สรุปผิด). text บน gradient/รูปต้อง verify ด้วยตา/ระบุ bg layer ไม่ใช่ getComputedStyle node เดียว.
- **Discovery**: chrome-devtools MCP `emulate` tool **ไม่มี param `prefers-reduced-motion`** (มีแค่ colorScheme/
  cpu/network/geo/viewport/userAgent) — lessons เดิมบอก "สลับไป chrome-devtools emulate" แต่ tool จริงทำ
  reduced-motion ไม่ได้. workaround ที่ใช้ได้: `navigate_page` ด้วย `initScript` stub `window.matchMedia` ให้คืน
  `{matches:true}` เมื่อ query มี `prefers-reduced-motion` (รันก่อน page script ทุกครั้ง) — autoplay gate ที่อ่าน
  `matchMedia(...).matches` ใน JS จะเห็น true -> ไม่ตั้ง `setInterval`. ยืนยัน gate จริง (ไม่ใช่ slider ตาย) ด้วย
  control run **ไม่ stub** -> ต้อง advance (0->1). อ่าน active slide ผ่าน `aria-selected` แยก call + `await
setTimeout` ใน async eval ครอบ 1 interval (~6.5s). — **Why**: ถ้าเชื่อ lessons เดิมว่า emulate ทำได้จะติดตัน;
  initScript matchMedia stub เป็นทางเดียวที่ทดสอบ JS reduced-motion gate ได้จริงผ่าน MCP ปัจจุบัน (globals.css
  คุมแค่ transition ไม่หยุด interval — ต้องทดสอบ gate ที่ตัว JS).
- **Pattern**: audit/verify-only task ที่ทุก REQ ผ่าน -> ไม่แตะโค้ด component เลย ถูกต้องตาม task boundary;
  defect ของ section อื่น (console RSC-prefetch 404 ของ href placeholder) = บันทึก FINDINGS ใน tasks.md +
  เสนอวิธีแก้ (`prefetch={false}`) แต่ไม่แก้เงียบ. honesty: REQ ที่วัดเชิงตัวเลขไม่ได้ในรอบ (CLS ต้อง perf trace)
  บันทึก gap ว่า "โครงสร้างกัน shift แล้ว แต่ไม่ได้วัดเลข" ไม่กลบเป็น PASS. — **Why**: audit task value อยู่ที่
