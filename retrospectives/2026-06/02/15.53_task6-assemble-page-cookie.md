## Lessons Learned

- **Pattern**: "assemble page" task เป็นจุดที่ gap ของ requirement ระดับ section โผล่ — ก่อนประกอบ
  ให้ cross-check **ทุก section ใน REQ-1.1 (หรือ list ลำดับหน้า) เทียบกับ component ที่มีจริง + anchor
  ใน nav data**; REQ-13 (Articles) ไม่ถูก task 4 (static) หรือ task 5 (interactive) list เลย แต่ REQ-1.1
  ต้องมี + `MAIN_NAV` มี `#articles` -> assembly เป็นที่เดียวที่จับได้. สร้าง component ที่ขาดเป็น
  prerequisite ของ assembly (ไม่ใช่ scope creep — เป็น blocker ของ REQ-1.1) แล้ว **flag ดัง + บันทึก
  gap-fill ใน tasks.md** ไม่แก้เงียบ. — **Why**: task decomposition ที่แบ่ง static/interactive ตาม
  verify-modality ทำ section ตกร่อง (Articles เป็น static แต่ไม่อยู่ใน task 4 list); ไม่มี cross-check
  ลำดับหน้า = ส่งหน้าไม่ครบ section ทั้งที่ทุก task ย่อย "ผ่าน".
- **Pattern**: anchor scroll ใต้ sticky header คุมด้วย `section[id]{scroll-margin-top}` ที่ globals.css
  ที่เดียว (page-wide, owned by assembly task) — ไม่ต้องใส่ `scroll-mt-*` ไล่ทุก section component
  (แตะ task อื่น เปลือง + ชน boundary). section ที่ render `<section id>` เองอยู่แล้วได้ผลทันที. — **Why**:
  scroll offset เป็น page-level concern; selector เดียวครอบทุก anchored section ไม่ต้องแก้ component
  ของ task 4/5.
