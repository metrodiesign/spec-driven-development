- **Pattern**: focus ring สีต่อพื้น คุมที่ `globals.css` ด้วย global `:focus-visible`=ring-primary (พื้นสว่าง)

    region เข้ม แทนไล่ override ทุก element. verify ด้วยค่า `--tw-ring-color` ใน compiled CSS chunk (`}:focus-
visible{` เจาะ global, อย่าใช้ `:focus-visible{` ลอยเพราะแมตช์ descendant rule ด้วย) + live box-shadow.
- **Discovery**: strip utility ซ้ำด้วย perl substring — substring พื้นสว่างเป็น prefix ของ cluster พื้นเข้ม
