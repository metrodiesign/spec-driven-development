## Lessons Learned

(promote เข้า `.ai/shared/LESSONS.md` แล้ว — guard-normalize, hardening-self-block, parallel-file-partition + extend npm-audit `--omit=dev`)

- **Pattern**: guard flat-string = fail-open หลายทาง (`\rm`/quote/`sh -c`/`eval`/`/`-prefixed ref) — normalize detection-only ก่อน match + scope name-collision (SQL `truncate` vs coreutil `truncate -s`) + benign baseline ทุก block rule. — **Why**: regex ดูครบยังรอด escape idiom + over-block everyday code.
- **Discovery**: hardening guard block การใช้งานชอบธรรมของตัวเอง (read-only `git config core.hooksPath` query โดน tamper-detect; secret-scanner block fixtures ตัวเอง). — **Why**: tamper-detect เฉพาะ write ไม่ใช่ read; scanner exclude fixtures dir; doc secret ใช้ placeholder.
- **Pattern**: multi-agent edit → partition ตาม file-owner (disjoint) กัน conflict ไม่ต้อง worktree; เชื่อ integration verify หลังทุกกลุ่ม land เท่านั้น (fullsuite ก่อน repair = stale). — **Why**: builder verify เห็น edit ครึ่งทางของกลุ่มอื่น → test count มั่ว.
- **Pattern**: CI `npm audit --omit=dev --audit-level=high` (ไม่ใช่เปล่า) — gate prod surface, dev-chain ไม่ block ทุก PR, dev vuln เปิด issue แยก. — **Why**: audit เปล่าแดงทุก PR จาก devDep เก่า; `fix --force` downgrade core เป็น breaking.
