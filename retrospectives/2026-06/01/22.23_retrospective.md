## Lessons Learned

- **Pattern**: form ที่มี pure validation lib อยู่แล้ว → UI เก็บ raw string state + parse → null/number แล้วโยนเข้า lib, อย่า duplicate validation ใน component. — matters: validation 2 ที่จะ drift; lib เป็น single source ปิด acceptance ได้ก่อน wire UI.
- **Discovery**: ไม่มี semantic token สำหรับ state ใหม่ (error/danger) → เพิ่ม token ใน config ที่เดียว ไม่ hardcode utility สี. — apply: ก่อนใส่สีใหม่ใน component, grep token ก่อน; ไม่มี = เพิ่มที่ config.
