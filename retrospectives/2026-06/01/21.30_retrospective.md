## Lessons Learned

- **Pattern**: เมื่อ design.md มีตารางตัวเลข + ตัวอย่างยืนยัน → คำนวณ expected ทุกแถวด้วยมือใส่ใน test table แทน snapshot → test เป็น executable spec ที่ deterministic. - Why: snapshot ลอยรับค่าผิดเงียบๆ; ค่าที่คำนวณมือ fail ทันทีถ้าสูตรเพี้ยน.
- **Discovery**: pre-flight check (dependency installed? config glob? upstream type?) ก่อนเขียนโค้ด ตัด blocker กลางคัน. - How to apply: task ที่ depends on task อื่น ให้ verify artifact ของ dependency มีจริงก่อนเริ่ม.
