## สิ่งที่ควรปรับปรุง (What Could Improve)

- ไม่ได้ลอง import data จริงผ่าน runtime (เช่น node -e นับ `.length`) — พึ่ง grep ล้วน; acceptable สำหรับ task เล็กแต่ borderline
