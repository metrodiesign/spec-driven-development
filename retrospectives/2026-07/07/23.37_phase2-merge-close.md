## Lessons Learned

- **Pattern**: squash-merge บีบทุก commit ของ branch เป็นก้อนเดียว → **merge commit title เชื่อไม่ได้ว่า "อะไรลง"**. เคสจริง: PR #45 title = `docs(spec): platform-phase2 ...` (auto-pick จาก commit แรก) ทำให้ดูเหมือน merge แค่ spec docs ทั้งที่ content = 71 files ครบทั้ง impl (tasks 1-9) + docs; commit เดิม `cc22434..26b8df6` ไม่โผล่แยกบน target เพราะโดน flatten. ยืนยันด้วย **content ไม่ใช่ title**: `git diff --stat <merge>^..<merge>`, `git ls-tree -r <branch>` เช็คไฟล์จริง, `git branch -r --contains <sha>`. — **Why**: เกือบตื่นตูมว่า impl ไม่ลง/ต้อง re-merge เพราะอ่าน title; squash workflow (repo นี้ merge PR แบบ squash) ทำให้ title เป็น proxy ที่หลอกได้เสมอ.
