## Lessons Learned

- **Pattern**: boundary/marker rule ของ shared iterator ต้องแก้ใน iterator ไม่ใช่ per-consumer และนิยาม token (เช่น `Evidence:` header) ต้องยึด enforcement floor เป็น canon — **Why**: fix per-consumer ทำ sibling consumer (CI gate) เปิดช่อง fake coverage + นิยาม case-sensitive ที่แคบกว่า floor คืนช่องโหว่เดิมทั้งก้อน — **Classification**: mechanized (promoted → `.ai/shared/LESSONS.md` [#shared-iterator-boundary-altitude])
- **Pattern**: issue body ของ spec-sync ต้องเป็น pure function ของ spec artifacts — เกือบใส่ "Post-review" prose เพิ่มใน #101 ซึ่งจะทำ re-run hash churn ตลอดกาล — **Why**: idempotency contract ของ projection พังเงียบถ้า render มี input นอก artifacts — **Classification**: advisory (ไม่ promote — เป็นข้อความที่ skill spec-sync-github ประกาศอยู่แล้ว ครั้งนี้แค่เกือบละเมิดเอง)
- **Discovery**: review 2 รอบชนบรรทัดเดียวกันคนละชั้น — Codex เจอ symptom (transcript รั่ว), fanout เจอว่า fix อยู่ผิด altitude + 2 fake-resolve paths ที่ claim ใน design ปฏิเสธ — **Why**: ยืนยันคุณค่า pre-merge fanout gate แม้หลังผ่าน bot review แล้ว (ตรงกับ lesson เดิม post-merge-review-still-finds-bugs แต่เลื่อนมาก่อน merge สำเร็จ) — **Classification**: advisory (กลไก = merge-pr step 1.5 ที่มีอยู่แล้ว)
